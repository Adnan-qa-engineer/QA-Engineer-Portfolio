Bug Report 001

Field| Details
Bug ID| BUG-001
Bug Title| Login button does not respond with valid credentials
Environment| Google Chrome, Windows 11
Preconditions| User must have a registered account
Test Type| Functional Testing
Severity| High
Priority| High
Bug Status| New

Steps to Reproduce

1. Open the E-Commerce website.
2. Navigate to the Login page.
3. Enter a valid registered email address.
4. Enter a valid password.
5. Click the Login button.

Expected Result

User should successfully log in and navigate to the dashboard.

Actual Result

Login button does not respond, and the user remains on the Login page.

Bug Description

The Login functionality fails when the user enters valid credentials and clicks the Login button.

QA Recommendation

The development team should investigate the Login button functionality and resolve the issue. QA should perform Retesting after the fix and Regression Testing to ensure other login-related features work correctly.
